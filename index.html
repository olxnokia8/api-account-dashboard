Proxy niedostępne. Odczyt zużycia OpenAI wymaga serwerowego proxy (przeglądarka blokuje bezpośrednie połączenie z api.openai.com). Rozwiązania: (1) wdróż przez Netlify CLI lub Git (funkcje serwerowe wdrażają się automatycznie), albo (2) wklej adres własnego proxy w Ustawieniach — do paczki dołączono gotowy skrypt cloudflare-worker-proxy.js (wdrożenie przez wklejenie kodu, za darmo).

Ustawienia zaawansowane — adres proxy (opcjonalnie)

Do pliku ZIP dołączono skrypt cloudflare-worker-proxy.js — wklej go w Cloudflare Dashboard → Workers & Pages → Create → Worker, a następnie wklej tutaj adres worker-a. Proxy jest wymagane tylko do odczytu OpenAI; OpenRouter działa bezpośrednio. Adres proxy jest zapisywany wyłącznie w Twojej przeglądarce (localStorage).
